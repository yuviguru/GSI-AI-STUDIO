What changed in Revised B

Before (scattered)
  • HUD card clipped by the camera notch — only ~12px of clearance.
  • Mascot took a 260×260 stage in the centre with lots of empty padding.
  • Portals scattered around the edges — looked playful but only the icon + label were visible (no tagline copy).
  • Vertical stacking left only ~50px of room for the Resume CTA + group switcher → cramped at the bottom.
After (arranged grid)
  • HUD pushed down ~24px (pt-7 + safe-area inset) so it sits clearly below the notch.
  • Mascot is now a 150px-tall horizontal strip — smaller mascot (size="lg") flanked by the side action stacks.
  • Portals laid out as a CSS grid: grid-cols-3 for Create / Play, grid-cols-2 for Learn. All 6 Create modes visible on one screen with no scroll.
  • Each portal shows the icon (circular halo) + label + 1-line tagline — visual style matches the scattered prototype, layout is disciplined like Variant A.
  • Resume CTA now reads ▶ Resume · Dragon Story · Ch 3 on a single line so the group switcher fits under it without overlap.

Verified layout (390×844, real React build)

  • HUD card: top 28 → bottom 89.
  • Mascot strip + side stacks: y ≈ 100 → 250.
  • Portal grid: top 353 → bottom 597 (6 cards, 2 rows, centered vertically in the gap).
  • Resume CTA: top 683 → bottom 715.
  • Group switcher: bottom 749 (10px buffer before the TabBar).
